# Project 1. The Letters

멜버른에서 한국으로 보내는 편지 프로젝트 소개 페이지. 사진·문구를 채워 넣고, 아래 신청 폼으로 편지를 받고 싶은 사람의 이름과 우편 주소를 받을 수 있어요.

## 폴더 구조

```
.
├── index.html        페이지 본문
├── css/style.css      스타일 (라이트/다크 모드 자동 대응)
├── js/script.js        사진 placeholder, 신청 폼 동작
├── assets/                사진을 넣는 폴더 (photo.jpg)
└── README.md
```

## 로컬에서 확인하기

`index.html` 파일을 브라우저로 더블클릭해서 열면 바로 확인할 수 있어요. (별도 빌드 과정 없음)

## 내용 채우기

- **사진**: `assets` 폴더에 `photo.jpg` 파일을 넣어주세요. 파일이 없으면 점선 placeholder가 대신 보여요.
- **문구**: `index.html`에서 `[ ]`로 표시된 세 개의 문단을 원하는 내용으로 바꿔주세요.
- **받는 이메일 주소**: `js/script.js` 맨 위 `RECEIVER_EMAIL` 값을 원하는 주소로 바꿔주세요. (신청 폼을 누르면 이 주소로 이메일이 작성돼요)

## 신청 폼은 어떻게 동작하나요?

별도의 서버 없이도 작동하도록, "신청 보내기" 버튼을 누르면 입력한 이름·주소가 담긴 이메일이 자동으로 작성돼요 (mailto 링크). 방문자가 보내기만 누르면 신청이 완료돼요. 로그인이나 데이터베이스가 필요 없어서 정적 사이트로 그대로 배포할 수 있어요.

## GitHub Pages로 배포하기

1. 이 폴더를 GitHub 저장소에 푸시하세요.
2. 저장소의 **Settings → Pages**로 이동하세요.
3. **Source**를 `Deploy from a branch`로, 브랜치를 `main` (또는 사용 중인 기본 브랜치), 폴더를 `/ (root)`로 선택하세요.
4. 저장 후 몇 분 뒤 안내되는 주소(`https://<사용자명>.github.io/<저장소명>/`)로 접속하면 페이지가 보여요.
